Claude Code is Anthropic's coding [agent](/agents/agent.md): a terminal-native
[harness](/harness/harness.md) running Claude.

Claude code usage can be traced via LangSmith using this [plugin](https://docs.langchain.com/langsmith/trace-claude-code).
