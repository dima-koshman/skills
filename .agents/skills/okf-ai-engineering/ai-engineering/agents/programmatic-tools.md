Programmatic tools give an agent a way to make tool calls in a scripted way, allowing for reduced token usage and orchestration of long running tasks.

Examples of programmatic tools implementations:

- [LangChain Interpreters](https://docs.langchain.com/oss/python/deepagents/interpreters)
- [Claude Workflows](https://code.claude.com/docs/en/workflows)
