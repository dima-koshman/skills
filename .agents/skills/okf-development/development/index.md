# communication

* [gRPC](/communication/grpc.md) `[Standard]` - RPC framework using Protocol Buffers as its IDL to generate client and server stubs — a service-to-service alternative to REST.
* [Protocol Buffers](/communication/protobuf.md) `[Standard]` - Language-neutral binary serialization for small structured records — schema-first `.proto` definitions compiled into native bindings.

# infrastructure

* [Data, Control & Management Planes](/infrastructure/planes.md) `[Technique]` - The decomposition of a distributed system into traffic-carrying, policy-distributing, and operator-facing layers.
* [Service Mesh](/infrastructure/service-mesh.md) `[Technique]` - A dedicated infrastructure layer handling service-to-service routing, security, reliability, and observability outside application code.
