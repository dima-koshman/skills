# Antigravity

Google's agent-first development platform built on Gemini — an IDE, desktop app, and CLI sharing one agent harness.

Reference: <https://antigravity.google>

Antigravity is Google's agent-first development platform built on Gemini: an IDE, a
desktop app, and a CLI that share a common [agent](agent.md)
[harness](../harness/harness.md), where agents operate across the editor, terminal,
and browser to build software from a prompt.
