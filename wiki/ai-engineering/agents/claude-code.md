# Claude Code

Anthropic's coding agent — Claude in a loop with file, shell, and code tools, available as CLI, IDE extension, and SDK.

Reference: <https://code.claude.com/docs>

Claude Code is Anthropic's coding [agent](agent.md): a terminal-native
[harness](../harness/harness.md) running Claude.

Claude code usage can be traced via LangSmith using this [plugin](https://docs.langchain.com/langsmith/trace-claude-code).
