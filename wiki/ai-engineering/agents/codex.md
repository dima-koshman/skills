# Codex

OpenAI's coding agent — an open-source terminal CLI plus cloud environments, powered by OpenAI's coding models.

Reference: <https://openai.com/codex/>

Codex is OpenAI's coding [agent](agent.md): an open-source terminal CLI
plus cloud environments and IDE integration, powered by OpenAI's frontier coding
models. It runs tasks end-to-end — features, refactors, migrations — with agents
working in parallel across git worktrees.
