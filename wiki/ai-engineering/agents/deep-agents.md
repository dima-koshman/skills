# Deep Agents

Opinionated LangChain package for high level agent patterns.

Reference: <https://docs.langchain.com/oss/python/deepagents/overview>

Deep Agents is the LangChain library that packages production [agent](agent.md) patterns — planning, [subagents](../harness/subagents.md), durable [memory](../context/memory.md), human-in-the-loop, and [workflows](../harness/workflows.md) — on top of LangGraph, which serves as its [harness](../harness/harness.md).
