# OpenCode

Open-source, terminal-native, model-agnostic coding agent — a vendor-neutral alternative to Claude Code.

Reference: <https://opencode.ai>

OpenCode is an open-source, terminal-native coding [agent](agent.md) (by
the SST team) that is model-agnostic — it connects to many model providers rather
than a single vendor, runs locally, and stores its sessions on disk. A
vendor-neutral counterpart to [Claude Code](claude-code.md). Can be used with Codex or Antigravity subscriptions, but not with Claude.

OpenCode usage can be traced via LangSmith using this [plugin](https://docs.langchain.com/langsmith/trace-with-opencode).
